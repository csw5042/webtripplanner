# 여행한칸 HTML 프로토타입

여행 선택부터 날짜별 상세 활동 입력까지 지원하는 설치형 웹앱(PWA) 프로토타입입니다. 기존 iOS 및 Windows 프로젝트와 독립적으로 동작합니다.

## 실행

Windows에서는 `Run-WebTripPlanner.cmd`를 더블 클릭하세요. 로컬 서버가 실행되고 기본 브라우저에서 `http://127.0.0.1:4173`이 열립니다. 터미널 창은 사용하는 동안 닫지 마세요.

`index.html`을 직접 열어도 일정 작성과 저장은 작동하지만, 앱 설치·브라우저 알림·일부 지도 기능은 로컬 서버에서 실행할 때 더 안정적입니다.

## 구현 기능

- 여러 여행 생성, 선택, 수정 및 삭제
- 시작일과 종료일을 기준으로 날짜 탭 자동 생성
- 날짜별 활동을 시간순 타임라인으로 표시
- 비행, 숙소, 음식점, 지하철, 기차, 차량, 관광, 쇼핑, 기타 활동
- 활동 종류별 항공편·역·숙소·예약 정보 등 맞춤 입력
- OpenStreetMap 기반 음식점 종류별 장소 검색과 지도 선택
- 시작/종료 시간 또는 하루 종일 설정
- 통화별 예상 금액 입력과 단일 통화 여행의 합계 표시
- 메모, 사진 여러 장, 웹 링크 저장
- 활동 수정 및 삭제
- 브라우저 알림
- 반응형 모바일 화면과 PWA 설치 정보
- 2026년 도쿄 5박 6일 추천 일정을 새 여행으로 불러오기
- 동네친구 강나미·추성훈 채널 기반 도쿄 맛집 13곳 검색 및 지역 필터
- 편의점별 추천 음식과 마트 음식 카테고리·구매 우선순위
- 일정·맛집·편의점·마트 이미지 확대 보기와 전체 조사 메모 내려받기

## 데이터 및 제한 사항

일정과 축소된 사진은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 지우면 함께 삭제되므로 중요한 일정은 별도 백업 기능을 추가하는 것이 좋습니다.

지도 검색은 OpenStreetMap 및 Nominatim을 사용하므로 인터넷 연결이 필요합니다. 브라우저 알림은 이 프로토타입 페이지가 실행 중일 때만 확인되며, iPhone에서 앱이 완전히 종료된 상태의 예약 알림을 보장하려면 서버 기반 웹 푸시 또는 네이티브 앱이 필요합니다.

## iPhone 홈 화면에 설치

1. 이 폴더를 HTTPS 웹 서버에 배포합니다.
2. iPhone Safari에서 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가**를 선택합니다.

로컬 PC 주소는 같은 Wi-Fi 네트워크 설정이 추가로 필요하며, 일반적인 PWA 설치와 알림 사용에는 HTTPS 배포를 권장합니다.
